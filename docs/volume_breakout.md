# 放量突破：双年收益达标的研究候选

**相同参数下，2025 和 2026 年截至 2026-10-09 的回测收益均超过 100%；没有证明能够稳定盈利。** 完整 2020–2026 回测最大回撤为 **59.22%**，2020、2021、2024 年亏损；对放量阈值敏感，且参数已用历史结果筛选。它是研究成果，不是对未来收益的承诺。

实现：[pattern_rotation.rs](../src/strategy/pattern_rotation.rs)。`volume-breakout` 是 `pattern-rotation` 的命令别名，使用同一套默认参数。

```bash

cargo run --release -- bt --start 20260101 --end 20261009 volume-breakout
```

## 与原策略的区别

这是一种事件入场、独立退出的趋势策略，不按低成交额挑股票，也不每天强制换成排名第一的股票。成交额仅用于可交易性门槛及相对放量信号。

1. 股票池为当日已生效的创业板指历史成分。排除上市不足 240 自然日、当日无行情、ST、退市整理期、历史不足、原始收盘低于 3 元、前 20 根日线平均成交额低于 3,000 万元的股票。
2. 入场必须同时满足：复权收盘严格突破**此前** 120 根日线的最高价；120 日复权收益至少 20%；当日成交额至少是此前 20 根日线均值的 2 倍。当前日不进入突破高点和平均成交额的基准窗口。
3. 市场广度是合格成分中收盘高于 120 日均线的比例。至少 50% 才允许新开仓；低于 40% 对持仓发出清仓指令。
4. 有空位时，按当日放量倍数降序选择，平分时按代码排序。默认最多持有 1 只，单次建仓目标预算为权益的 70%，权重单包含交易费用。不每日补仓或减掉上涨造成的超配，所以 70% 不是持仓期间的硬上限。
5. 持仓出现以下任一条件即退出：收盘跌破 10 日均线；相对入场开盘价及其后最高收盘价回落至少 12%；持仓达到 60 个交易日；市场广度退出；ST/退市整理期状态或退出指数成分。12% 是收盘信号阈值，**不是保证成交的止损幅度，也不是账户回撤上限**。
6. 收盘发出订单，下一交易日开盘撮合。退出指令一旦生成，会持续尝试直至卖出；停牌或跌停不会被假设为已成交。只有实际卖出后，才把该持仓名额用于新股票。卖出与新买入若在同日发生，按预计卖出后现金计算买入权重，避免意外集中仓位。

均线、收益、价格高点使用各日原价乘各日复权因子；成交额和最低价过滤保持原始口径。没有按年份分支、事后股票名单、杠杆或修改引擎的收益算法。

## 稳定性检查：尚不合格

下面每行都从 2025 年开始**连续运行**，只改变所列参数，不逐年切换：

| 配置 | 2025 收益 | 2026 收益 |
| --- | ---: | ---: |
| 默认配置 | 133.94% | 151.71% |
| 双边佣金提高到千一 | 132.91% | 145.16% |
| 建仓预算改为 60% | 114.22% | 118.89% |
| 建仓预算改为 80% | 151.69% | 182.00% |
| 放量门槛改为 1.5 倍 | 12.69% | 77.86% |
| 放量门槛改为 2.5 倍 | 49.07% | 50.90% |
| 入场广度改为 40% | 105.28% | 121.35% |
| 入场广度改为 60% | 230.18% | -0.76% |
| 持仓数改为 2 只 | 119.60% | 59.94% |

增加佣金不能替代滑点、排队或容量模拟；本引擎没有这些模型。2025 独立账户仅完成 7 次买卖，最大盈利一笔贡献当年净利润的 **68.58%**；2026 对应比例为 **23.79%**。收益依赖少量趋势行情及单股集中持仓，放量门槛和市场过滤的敏感性明显。

本次研究已经查看并筛选过 2025、2026，也查看了更早年份，因此**不存在可宣称为未参与选型的样本外测试期**。按历史结果选出的规则需要未来逐日记录验证；现有证据不足以称为稳定高额盈利。

## 研究范围与复现工具

实现并比较了七类规则：

| `--pattern` | 机制 |
| --- | --- |
| `breakout` | 放量突破；支持风险调整动量、纯动量、放量倍数排名 |
| `pullback` | 中期趋势向上时买入短期回落 |
| `rsi-reversion` | 用短期涨跌收益和计算的简化 RSI 做趋势内反转 |
| `compression` | 中期高点附近的短期收益均方根收缩 |
| `recovery` | 放量、长下影且日内上涨 |
| `smooth-trend` | 较平稳的中期上涨与短期趋势确认 |
| `online-alpha` | 滚动岭回归预测，依靠历史已成熟样本更新 |

研究股票池包括历史 `399101.XSHE`、`399006.XSHE`、`000905.XSHG` 及指数并集；`--symbol` 支持逗号分隔。比较过数百次配置运行，包含重复和修复前实验，正式数字只取最终代码重新核验的结果。早期探索还发现并修复了先卖后买时的权重预算问题；不把修复前结果当成最终绩效。

`online-alpha` 使用 16 维价量特征（含截距和交互项）。信号次日开盘为目标入场参考，经过 `--prediction-days` 后的开盘为目标退出参考；**只有到达退出日期后**才加入标签。缺少指定日开盘的样本不使用。训练窗口默认 126 个交易日，至少 500 个有效标签才预测，岭系数默认 0.1；标签将收益裁剪到 ±50% 后扣除固定 11 基点预估成本，真实回测仍单独使用引擎实际费用。每次启动从空模型训练；该模型没有优于选中的突破候选，不将其宣传为已验证的机器学习优势。

中证 500 的 2019 年部分日线缺失涨跌停数据，原校验仍报错；该股票池仅补齐并探索了覆盖 2025–2026 所需的较近期数据，没有据此声称其早期回测有效。最终创业板候选则已完成 2020–2026 正式核验。数据解析新增 `302` 号段支持，以免拒绝已存在的 `302132`；[深交所样本调整公告](https://investor.szse.cn/disclosure/notice/general/t20250603_613877.html)列出了该代码。

## 验证

- 111 项库测试通过，3 项真实联网测试按原设置忽略；Clippy 严格检查通过。
- 新增测试覆盖此前高点与复权、次日开盘、广度退出、跌停卖出重试、卖出失败不释放名额、同日卖买预算、不同模式条件和参数校验。
- 修改未来价格、复权因子及 ST 状态不会改变此前订单；在线学习测试也实际生成预测和买单，避免空模型造成无效测试。
- 学习标签成熟日期、缺失开盘及滚动过期均有测试。沿用 [README 的回测限制](../README.md#回测口径与限制)，没有启用未来数据或放宽撮合规则来达成收益目标。
