# 策略表现轮动：strategy-momentum

这是本轮找到的、在当前数据及撮合假设下同时满足三个历史指标的研究候选。2025 和 2026 年参与了参数选择，这不是样本外检验，也不证明以后能保持翻倍收益或 20% 以下回撤。

数据截止 **2026-10-09**。实际账户初始资金 10 万元，不加杠杆；佣金双向万三、最低 5 元，卖出印花税万五。信号收盘生成，下一交易日开盘执行，保留引擎的涨跌停、停牌、T+1、整手和费用约束。

## 规则与执行

先独立运行两个参考账户，均从 2020 年开始，初始资金各 10 万元：

- 防守参考：现有默认 `adaptive-rotation`，历史中小板成分内的低成交额反转轮动，6 个持仓。
- 进攻参考：`volume-breakout --allocation 0.95`，历史创业板成分内的放量突破。其他参数固定为现有默认值，详见复现脚本。

每日收盘计算两个参考账户过去 **40 个交易日**的净值收益。如果突破账户收益高于 **5%**，且高于反转账户，就跟随突破账户；否则跟随反转账户。观测不足 40 日时跟随反转账户。没有按年份、股票代码或未来收益切换规则。

实际股票目标权重是被选参考账户**当日收盘持仓权重乘以 80%**，参考账户空仓时实际账户也以现金为目标。目标差额超过组合权益的 2% 且超过 2000 元时调仓，完全落选的股票直接清仓。先卖后买，部分减仓使用 `Sell { price: None, .. }` 开盘卖出指定收益股数；`price: Some(限价)` 表示限价卖出，成交与费用由同一个回测引擎结算。

80% 是目标权重缩放系数，不是盘中硬上限，成交失败和价格变动仍会造成偏差；本次最高收盘股票仓位约 80.60%。参考账户各自已经扣除其模拟费用，实际账户另外扣除实际调仓费用，不是把两条参考净值直接相加。

参考持仓在当天收盘才可观察，实际账户在次日开盘跟随，所以与直接执行子策略相比有额外延迟；这个延迟已包含在上述结果中。

独立年度账户只重置实际资金，两个参考账户继续使用从 2020 年起的历史状态。这是相同的历史预热规则；不能将其解释为“2025/2026 年才从零启动所有参考模型”。年初持仓、资金规模和整手限制也解释了两种年度收益口径的差异。

## 复现

当前本地缓存及已有官方日历报告覆盖所需区间。一次生成参考账户、完整账户、独立年度、费用压力与参数敏感性报告：

```bash
cargo build --release --example rotation_study
python3 examples/study_strategy_momentum.py \
  --calendar-report report/volume_breakout-1010-231929/result.json \
  --end 20261009 --sensitivity --prefix-check
```

脚本保存每次运行的完整命令、指标、结果文件及源码 SHA-256。默认输出 `report/strategy_momentum/`。参考报告准备好后，正常 CLI 可生成 HTML：

```bash
cargo run --release -- bt --start 20200101 --end 20261009 \
  strategy-momentum \
  --core-report report/strategy_momentum/core.json \
  --satellite-report report/strategy_momentum/satellite.json
```

独立年度改为 `--start 20250101 --end 20251231` 或 `--start 20260101 --end 20261009`，策略参数保持不变。默认窗口 40、收益门槛 0.05、配置比例 0.8、进攻状态突破权重 1、再平衡容忍度 0.02。

`strategy-momentum` 当前是**读取历史参考账户报告的研究实现**，没有连接实盘或自动维护参考账户。延长回测日期前必须先重新生成覆盖新日期的两份参考报告；缺失日期会报错，不能将最后一个信号无限沿用。输入报告必须由可因果运行的策略生成，读取任意外部报告本身并不能保证其没有未来数据。

## 敏感性与审计

以下均为同一 2020–2026 连续账户，仅改表中参数，其余使用默认值：

| 变更 | 2025 收益 | 2026 收益 | 全周期回撤 | 三条件通过 |
|---|---:|---:|---:|---|
| 默认 40 日窗口 | 126.90% | 122.30% | 16.45% | 是 |
| 30 日窗口 | 89.48% | 138.46% | 27.02% | 否 |
| 35 日窗口 | 102.10% | 120.78% | 18.79% | 是 |
| 45 日窗口 | 139.01% | 145.60% | 19.09% | 是 |
| 50 日窗口 | 97.68% | 130.93% | 19.18% | 否 |
| 收益门槛 0% | 109.58% | 120.78% | 16.38% | 是 |
| 收益门槛 10% | 102.96% | 127.29% | 16.33% | 是 |
| 配置比例 70% | 107.20% | 101.01% | 14.36% | 是 |
| 配置比例 90% | 148.75% | 142.66% | 18.38% | 是 |
| 实际账户佣金千一 | 119.72% | 118.95% | 16.33% | 是 |

费用压力只提高实际账户费用，参考账户的信号计算继续使用基准费率；这不是重新训练后的结果，也不能代替滑点模拟。相邻参数并非全部通过，35 日和 70% 配置的部分年份也仅略超过门槛。

删除两份参考报告中所有 2025–2026 数据、从源策略重新回测到 2024 年，再运行实际账户，2020–2024 的净值、成交和拒单记录与完整回测前缀逐项相同。单元测试还检查更改未来净值不影响较早目标持仓，以及参考日历不一致、无效净值的拒绝处理。

`examples/verify_backtest.py` 独立从实际权益逐日重算收益、最大回撤及夏普。新增加的部分卖出订单仍使用原引擎的可卖数量、收益单位、费用和涨跌停检查，没有更改历史收益结算公式。

本轮也检验了固定比例组合及市场动量/波动过滤，未找到同时满足三条件的结果。最终窗口和配置比例经过历史筛选，2025、2026 不能再作为未见样本。当前引擎没有滑点、排队或容量模型，日线收盘回撤也不代表盘中最大亏损；下一步的有效检验应是冻结规则后的新增行情。
